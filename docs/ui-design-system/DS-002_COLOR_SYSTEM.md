# DS-002 — Color System

## Foundation
Use neutral surfaces with restrained accent colors.

Suggested semantic token groups:
- `bg.canvas`
- `bg.surface`
- `bg.subtle`
- `border.default`
- `text.primary`
- `text.secondary`
- `text.muted`
- `accent.primary`
- `accent.hover`

## Semantic Status
- success: green
- warning: amber
- danger/error: red
- info: blue
- neutral/inactive: gray
- pending/processing: violet or blue-violet

## Financial Semantics
- positive amount / gain: green
- negative amount / loss: red
- neutral balance/cost: primary text
- current market value: accent/blue family
- cost basis: neutral
- unrealized gain/loss: semantic positive/negative

## Rule
Color is never the only carrier of meaning. Pair color with text, icon, badge, or sign.
