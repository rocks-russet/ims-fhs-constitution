# DS-003 — Typography

## Goals
Readable at data-dense scale and clear in financial figures.

## Roles
- Display: dashboard headline / major total
- Heading 1–3: screen and section hierarchy
- Body: default UI content
- Label: form/table metadata
- Caption: timestamps, provider/source, secondary context
- Mono: IDs, order numbers, inventory numbers, transaction references

## Numeric Data
Use tabular numerals where available for:
- IDR values
- percentages
- quantities
- timestamps
- counters

## Rule
Business IDs such as `INV-...`, `PUR-...`, `ORD-...` should be visually distinguishable and easy to copy.
