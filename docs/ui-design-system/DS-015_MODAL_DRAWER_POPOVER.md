# DS-015 — Modal, Drawer & Popover

## Modal
Use for:
- focused confirmation
- short form
- destructive confirmation
- compact decision

Do not use a modal for complex multi-step workflows that need full context.

## Drawer
Use for:
- quick detail
- filters
- column chooser
- contextual inspection

## Popover
Use for compact controls, menus, and metadata.

## Rule
Avoid nested modals.
