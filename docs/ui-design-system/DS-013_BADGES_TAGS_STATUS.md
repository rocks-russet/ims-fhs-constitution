# DS-013 — Badges, Tags & Status

## Status Badge
Used for workflow/state:
- AVAILABLE
- LISTED
- RESERVED
- SOLD
- WAITING_PAYMENT
- PAID
- PACKING
- SHIPPED
- COMPLETED
- CANCELLED
- APPROVED / REJECTED / PENDING

## Tags
Used for descriptive grouping, not workflow authority.

## Rules
- status vocabulary matches BR exactly
- badge color + text
- avoid excessive colors in the same row
- status badge must remain readable in light/dark themes if dark mode is later enabled
