# DS-011 — Tables

## Core Capabilities
- sticky header
- sortable columns
- resizable columns
- reorderable columns
- hide/show columns
- column chooser
- row selection
- pagination
- density preference
- horizontal scroll only when genuinely required

## Optional Capabilities
- pinned columns
- bulk actions
- saved views
- inline status badges
- expandable row details

## Header Sorting
Click sortable header:
- ascending
- descending
- reset/default

## Rule
Table configuration is user-specific and must not alter another user's view.

## Financial Data
Money columns use right alignment and tabular numerals.
