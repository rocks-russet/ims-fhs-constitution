# DS-001 — Design Philosophy

## Direction
IMS FHS uses a hybrid visual direction:
- GitHub for data-dense explorers and tables
- Stripe for financial/portfolio dashboards and summaries
- Linear for forms, detail pages, motion, and interaction clarity

## Principles
1. Operational clarity before decoration.
2. Dense information without visual clutter.
3. Fast scanning of status, ownership, cost, market, and workflow state.
4. Strong visual hierarchy for money, inventory identity, and critical actions.
5. Predictable interaction patterns across all modules.
6. UI must remain usable for long daily sessions.
7. Important mutation states are explicit: VALIDATING → COMMITTING → SUCCESS / ERROR.
8. No hidden critical action behind ambiguous icon-only controls.
9. Desktop-first for operations, responsive for read/review on smaller screens.
10. Business terminology follows Constitution vocabulary exactly.
