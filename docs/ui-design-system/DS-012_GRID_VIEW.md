# DS-012 — Grid View

## Purpose
Visual browsing for Inventory/Product assets.

## Card Contents
Depending on asset type:
- image
- card/product name
- card number / variant
- owner
- status
- cost
- market value
- gain/loss
- holder/storage summary

## Rules
- responsive card size
- image remains prominent but does not hide key operational data
- click opens Detail
- active search/filter/sort state matches List View
