# DS-021 — Responsive & Accessibility

## Desktop
Primary operational target.

## Tablet
Support reading, review, approval, search, and moderate editing.

## Mobile
Support essential dashboard/detail/review actions; complex dense-table operations may use adapted layouts.

## Accessibility
- keyboard navigation
- visible focus
- sufficient contrast
- semantic labels
- screen-reader-friendly form errors
- touch targets appropriately sized
- no color-only status meaning
