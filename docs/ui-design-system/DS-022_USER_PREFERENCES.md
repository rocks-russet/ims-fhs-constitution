# DS-022 — User UI Preferences

## Persistable Preferences
Per user:
- Grid/List preference
- table density
- visible columns
- column order/width
- sort
- saved filter presets
- dashboard widget preference where later approved

## Rules
- preferences are presentation only
- never change business data/authorization
- invalid/deprecated preferences fall back safely
- reset-to-default is always available

## Future
Dark mode may be supported as a user preference after visual review; v1 mockups may focus on one approved theme first.
