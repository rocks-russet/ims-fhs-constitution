# DS-018 — Charts & Data Visualization

## Use
Charts are secondary to precise numeric values.

Appropriate:
- portfolio value trend
- realized profit trend
- owner/category breakdown
- seller/buyer market variance distribution
- wallet movement

## Rules
- always provide exact value tooltip/table alternative
- use semantic financial colors consistently
- chart period/source/freshness visible
- current market provider noted where valuation depends on it
- avoid decorative 3D charts
