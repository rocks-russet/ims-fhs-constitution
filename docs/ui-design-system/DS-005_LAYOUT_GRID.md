# DS-005 — Layout & Grid

## Application Shell
- persistent primary navigation
- screen title/header region
- optional contextual toolbar
- main content canvas
- optional right drawer/inspector

## Width
Data-heavy screens may use full-width layouts.
Detail/forms should use readable maximum widths unless comparison benefits from wider layout.

## Grid
Use responsive 12-column logic where useful, but components may use CSS grid/flex layouts internally.

## Dashboard
Summary cards should avoid excessive vertical stacking. Prefer balanced horizontal rows on desktop.
