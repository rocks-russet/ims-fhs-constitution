# DS-006 — Surfaces, Elevation & Radius

## Surfaces
- Canvas: application background
- Surface: cards/panels
- Raised Surface: popovers, dropdowns
- Overlay Surface: modal/dialog

## Elevation
Use subtle elevation; avoid heavy shadows.

## Radius
Use a restrained consistent radius system:
- small: inputs/badges
- medium: cards/panels
- large: modal/hero surfaces

## Rule
Elevation communicates layering, not decoration.
