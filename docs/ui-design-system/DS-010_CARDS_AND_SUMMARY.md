# DS-010 — Cards & Summary Components

## Summary Cards
Use for:
- Wallet Balance
- Portfolio Cost Basis
- Market Value
- Unrealized Gain/Loss
- Order counts
- Pending approvals

## Rules
- primary metric large and scannable
- context/subtitle concise
- optional trend/breakdown secondary
- cards link to relevant detail/explorer where meaningful
- do not overload cards with full table content

## Horizontal Orientation
Where possible, summary sections should favor horizontal composition to avoid unnecessary page length.
