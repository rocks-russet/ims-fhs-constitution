# DS-004 — Spacing & Density

## Spacing Scale
Use a consistent 4px-based spacing scale.

Typical tokens:
- 4
- 8
- 12
- 16
- 20
- 24
- 32
- 40
- 48

## Density Modes
Tables/explorers support:
- Compact
- Comfortable
- Spacious

User preference may persist per account.

## Principle
Do not increase page length unnecessarily. Prefer horizontal grouping, progressive disclosure, tabs, drawers, or collapsible sections when information can remain discoverable.
