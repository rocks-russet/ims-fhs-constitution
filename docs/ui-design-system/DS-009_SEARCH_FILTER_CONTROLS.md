# DS-009 — Search & Filter Controls

## Search
Global search is prominent on Explorer screens.

## Filters
Support:
- quick filters
- advanced filter panel
- active filter chips
- clear-all

## Rules
1. Filters remain active when switching Grid/List view.
2. Hidden table columns may still be filtered.
3. Search/filter state may persist in user preferences where useful.
4. Result counts reflect active filters.
5. Empty results clearly distinguish 'no data' from 'no match'.
