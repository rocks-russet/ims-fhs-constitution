# FIN-BR-077 — FINANCIAL REPORT CERTIFICATION

Purpose:
Define governance for financial report certification.

Rules:
- All actions require traceable evidence.
- Historical financial records are immutable.
- Corrections use adjustment or reversal entries.
- Every action is attributable to an authorized actor.
- All related wallet, ledger, and reporting effects remain synchronized.
